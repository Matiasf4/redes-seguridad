# Herramientas de Redes con Python

Proyecto educativo con 8 ejercicios de Python para analizar redes, comprobar conexiones y conocer protocolos de comunicación.

## Índice
1. Requisitos
2. Ejercicios
3. Ejecución
4. Autor

## 1. Requisitos
- **Sistema operativo:** Windows, Linux o macOS.
- **Python:** 3.10 o superior.
- **RAM:** 2 GB mínimo.
- **Conexión a Internet:** Para pruebas externas.
- **Dependencias:** Solo bibliotecas estándar de Python.

## 2. Ejercicios

| N.º | Ejercicio | Descripción |
|---|---|---|
| 1 | Subred IPv4 | Calcula máscara, red, broadcast y hosts. |
| 2 | IP local | Muestra el nombre e IP del equipo. |
| 3 | Ping | Comprueba la conectividad de un host. |
| 4 | Barrido de red | Detecta equipos que responden al ping. |
| 5 | Puertos TCP | Comprueba puertos abiertos. |
| 6 | DNS | Resuelve dominios y mide tiempos. |
| 7 | Latencia TCP | Calcula tiempos y pérdidas de conexión. |
| 8 | HTTPS | Verifica el estado web y vencimiento TLS. |

## 3. Ejecución

Instalar Python desde https://www.python.org/

Abrir una terminal en la carpeta del proyecto y ejecutar:

```bash
python e01_subred.py
```

Cambiar el nombre del archivo para ejecutar otro ejercicio.
